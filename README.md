# 💸 Expense Tracker Web Application

A full-stack Expense Tracker built using Flask, SQLite, HTML, CSS, JavaScript, and Bootstrap
that helps users manage expenses, track spending, set budgets, and visualize financial habits.

---

## 🚀 Features

- User Registration & Login Authentication
- Secure Password Hashing
- Add / Edit / Delete Expenses
- Category-Based Expense Tracking
- Dashboard with Expense Summary
- Budget Limit Setting
- INR (₹) and USD ($) Currency Display
- Search & Filter Expenses
- Responsive Landing Page
- Modern UI with Bootstrap

---

## 🛠️ Tech Stack

### Backend:
- Python
- Flask
- SQLite

### Frontend:
- HTML
- CSS
- JavaScript
- Bootstrap
